# Anuncio de la semana 1
## Bienvenid@s a Lenguajes interactivos / Semana 1 / Experiencia 1

Estimadas/os participantes,

 

Bienvenidas y bienvenidos a la semana N°1 de Lenguajes Interactivos 100% online. Recuerda que nos encontramos explorando la Experiencia 1 “Estableciendo las bases para trabajar con Javascript”.

 

Durante esta semana trabajaremos en la Actividad Formativa 1: Trabajando con los elementos básicos de Javascript,  Durante la primera semana, realizarás una actividad formativa en la que tendrás que resolver distintos ejercicios prácticos relacionados con el uso de variables, bucles, operadores matemáticos y condicionales if-else y las funciones prompt, alerts (alertas), console.log (mensajes de consola), a fin de determinar si un número es par o impar programando en JavaScript.



A continuación, se presenta el Resultado de Aprendizaje (RA ) e Indicadores de Logro (ILs) asociados a la actividad: 

El RA1 Resultado de aprendizaje de esta actividad de Formativa es :



RA1. Utiliza elementos básicos de programación en JavaScript en sitio web, de acuerdo criterios de usabilidad y accesibilidad y los requerimientos del proyecto. 


Los IL1 y IL2 indicadores de logro que debes tener presente son:



IL1. Utiliza correctamente los elementos básicos de programación como variables, arrays, operadores (if - else) y bucles, a fin de dar solución a los requerimientos del proyecto. 
IL2. Utiliza el lenguaje JavaScript para programar funciones que permiten reutilizar código de manera eficiente. 


Para la realización de esta actividad individual, revisa los materiales de aprendizaje de esta semana. 

Descarga el archivo Trabajando con los elementos básicos de JavaScript, donde encontrarás las instrucciones específicas para cumplir con lo solicitado.  



Para entregar esta actividad, debes crear un archivo comprimido (.zip) con los archivos de tu proyecto y súbelo a plataforma.

Guarda el archivo con la siguiente nomenclatura: Exp1_S1_nombre_del_estudiante. Por ejemplo: EXP1_S1_Claudia_Álvarez 

Recuerda que esta actividad es formativa

Consulta la pauta de evaluación para saber cómo serás retroalimentada/o.
