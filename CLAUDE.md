# Plantilla de Estructura de Cursos - lenguajes-interactivos-001A-FINAL

## Descripción General

Este documento define la estructura y orden estándar para el curso **lenguajes-interactivos-001A-FINAL**. Puede ser utilizado como plantilla para organizar otras asignaturas o cursos.

## Estructura del Curso

El curso está organizado en **9 semanas**, cada una con una estructura consistente y predefinida.

## Organización por Semana

### Estructura de cada Semana

Cada semana (`semana-XX`, donde XX es el número de semana 01-09) debe contener:

```
semana-XX/
├── resumen-clase.md
├── ejercicio-resumen-clase.md
├── material-semana/
└── material-clase/
```

### Descripción de Archivos y Carpetas

#### 1. **resumen-clase.md**
   - Archivo en formato Markdown
   - Contiene el resumen de los conceptos y temas tratados en la clase
   - Debe incluir explicaciones claras y estructuradas
   - Sirve como referencia teórica

#### 2. **ejercicio-resumen-clase.md**
   - Archivo en formato Markdown
   - Contiene ejercicios prácticos relacionados con los temas del resumen
   - Los ejercicios refuerzan los conceptos aprendidos
   - Puede incluir preguntas, problemas o actividades

#### 3. **material-semana/**
   - Carpeta para almacenar material didáctico general de la semana
   - Puede contener: documentos, imágenes, videos, presentaciones, referencias
   - Organización interna a criterio del instructor/creador

#### 4. **material-clase/**
   - Carpeta para almacenar material específico utilizado en clase
   - Puede contener: códigos, ejemplos, demostraciones, slides
   - Organización interna a criterio del instructor/creador

## Especificaciones y Notas Importantes

### Nomenclatura de Semanas
- Cada semana debe nombrase como `semana-XX` donde XX es un número de dos dígitos (01-09)
- Esto asegura un ordenamiento alfabético y numérico consistente

### Archivos Obligatorios por Semana
- `resumen-clase.md` - OBLIGATORIO
- `ejercicio-resumen-clase.md` - OBLIGATORIO
- `material-semana/` - Carpeta debe existir (puede estar vacía)
- `material-clase/` - Carpeta debe existir (puede estar vacía)

### Consideraciones Generales
1. Mantener coherencia en la nomenclatura
2. Todos los archivos de resumen y ejercicios deben estar en formato Markdown (.md)
3. Las carpetas `material-semana/` y `material-clase/` pueden contener cualquier tipo de archivo
4. No modificar el archivo `README.md` si ya existe en la raíz
5. El archivo `CLAUDE.md` sirve como referencia y plantilla

## Uso como Plantilla para Otras Asignaturas

Para aplicar esta estructura a otro curso:

1. Crear un directorio raíz con el nombre del curso
2. Replicar la estructura de 9 semanas (o adaptar el número según sea necesario)
3. Seguir la nomenclatura exacta para archivos y carpetas
4. Copiar este archivo CLAUDE.md y adaptarlo al nuevo curso
5. Crear un README.md específico para el nuevo curso

### Adaptaciones Posibles
- Número de semanas: puede variar según la duración del curso
- Nombre del curso: adaptar según la materia
- Contenido: personalizar según los temas específicos
